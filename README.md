# WorldLink

A mobile-friendly voting link companion.

## Features
- Paste and validate an HTTP/HTTPS voting page URL.
- Save one voting link locally in the browser.
- Open the official voting page manually.
- Copy or share the saved link.
- Clear the saved link at any time.

## Run
Open `index.html` in a modern browser, or enable GitHub Pages for this repository (Settings → Pages → Deploy from a branch → `main` → `/ (root)`).

## Fair-use boundary
WorldLink does not automatically submit votes, generate repeated votes, evade rate limits, or bypass eligibility checks. Users must follow the voting organiser's rules.
